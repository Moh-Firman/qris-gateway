Internal Secret
Kunci penghubung Mini App / bot ke gateway

Secret ini dipakai aplikasi kamu (misal Mini App Store) saat meminta gateway membuatkan QRIS. Gateway hanya melayani request yang membawa secret yang cocok — jadi orang lain tidak bisa memakai gateway-mu. Secret harus sama persis di dashboard ini dan di pengaturan aplikasi kamu.

DANA Notify (APK)
Konfigurasi webhook notifikasi pembayaran

            
Pasang URL dan secret ini di aplikasi DANA Notify agar pembayaran otomatis terdeteksi dan saldo user langsung bertambah.

            
Webhook URL

            
/api/mutasi_notify

            
FormatPOST JSON

            
{
  "secret": "INTERNAL_SECRET_KAMU",
  "amount": 50000,
  "text": "opsional - keterangan"
}

            
Gunakan Internal Secret di atas sebagai nilai secret.
